# BNCP 자산·소모품 관리 최적화 대시보드

해외사업본부 개선 과제 **「자산(중장비·차량) 소모품 관리 최적화」** 를 한 화면에 정리한 대시보드입니다.

| 항목 | 내용 |
|---|---|
| 담당 | 해외사업본부 |
| 적용 분야 | (지원) 인력 효율화 |
| 적용 시점 | 중장기 |

## 구성

1. **추진 배경** – 수기 관리(AS-IS) → QR·AI 통합 관리(TO-BE), 관리 흐름(스캔 → 입출고 기록 → AI 분석 → 대시보드·발주 추천)
2. **주요 내용** – AI 기반 자산·소모품 관리 시스템 7대 기능
   - 수집·기록: QR 기반 관리, 입출고 자동화, 사용 이력 추적
   - AI 분석·예측: 이상 사용·분실 위험 탐지, 재고 부족 예측 및 자동 발주 추천
   - 모니터링·리포트: 자산 위치·상태 실시간 조회, 통합 대시보드
3. **기대효과** – 업무 효율 향상, 비용 절감, 자산 관리 고도화, 데이터 기반 의사결정
4. **추진계획**
   - '27년 2분기: 관리 대상 자산·소모품 목록 정리 (단기)
   - '27년 4분기: 엑셀·구글 연동 및 모바일 스캔 입력 시스템 개발 (단기)
   - '28년 2분기: 재고 예측·이상 사용 분석 모델 적용, 전 현장 확대 (중장기)
5. **고려사항** – 시스템 운영, 사용자, 데이터 관리, 운영 관리

## 보기

- **로컬**: `index.html` 을 브라우저로 열면 됩니다.
- **GitHub Pages로 게시**
  1. 새 저장소를 만들고 `index.html`, `README.md` 를 업로드합니다.
  2. 저장소 **Settings → Pages** 에서 Source를 `Deploy from a branch`, Branch를 `main` / `/(root)` 로 지정 후 저장합니다.
  3. 잠시 후 `https://<계정명>.github.io/<저장소명>/` 에서 확인할 수 있습니다.

> 참고: 폰트는 Google Fonts(IBM Plex Sans KR / IBM Plex Mono)를 불러오며, 오프라인에서는 시스템 기본 글꼴로 표시됩니다. 페이지의 QR 태그는 표기 예시이며 실제 코드가 아닙니다.
